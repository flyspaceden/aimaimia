# 全品类商品视觉优化 Agent 设计

> 状态：**Phase A 候选实现正在基于 `main` 审查迁移；尚未推送、迁移、部署或接入真实生成模型。**
>
> 本文是卖家商品图片优化的设计权威来源。它覆盖生鲜、智能手环、家电、包装品、美妆、服饰、家居等全品类；不把任一品类当作默认场景。

## 1. 核心结论

本功能不是“万能 AI 美图”。正式名称为 **真相锁定商品视觉 Agent（Truth-Locked Product Visual Agent）**：

```text
不可变规范安全源
  → 免费质量诊断
  → 风险档案 + 可执行处理合同
  → 原商品前景 / 蒙版
  → 免费保真合成 或 仅背景生成
  → 原前景强制回贴
  → 真实性闸门
  → 商家显式采用 → 审核 / A-B 实验
```

生成模型绝不能重画商品主体。最终图里的商品、包装、文字、二维码、数量、颜色、规格与可见瑕疵均须来自原始实拍前景；AI 只能生成或选择背景、光线氛围和画布空间。

这同时解决三个目标：提高商品流的专业感、把成本压在必要处、避免“图好看但实物不符”损害转化和信任。

## 2. 不可违反的产品规则

1. 规范安全源是第一期证据，永久保留且写入内容哈希；候选图只是可撤销版本。原始未处理上传在安全规范化后不保留，避免把联系方式或二维码作为可再分发资产；如有合法留存原件的需求，须另行设计权限与保留期。
2. 无论品类，商品主图不得由生成模型改变主体像素。
3. 高阶场景图只能是详情页营销附图，不能替代主图、包装图、规格图、瑕疵图或售后证据图。
4. 不提供自由提示词。商家选择“成品方向”，服务端按风险档案和模板构造固定处理合同。
5. Agent 从不自动发布、自动换封面或自动通过审核；商家采用与商品审核均为独立动作。
6. 图像无法被可靠救回时，Agent 必须给出重拍指引，不得伪造“高清”“新鲜”“无瑕疵”商品。

## 3. 用风险轴覆盖全品类

商品不按“是不是海鲜”路由，而是由图像和商品字段共同形成风险档案。

| 风险轴 | 例子 | 禁止的自动操作 |
|---|---|---|
| 身份文字 | 成分表、条码、型号、屏幕 UI、尺码、序列号 | 改字、去字、重画包装、重画二维码 |
| 外观事实 | 手环表带材质、手机接口、珠宝、木纹、二手磨损 | 改色、磨皮、修瑕疵、改接口/花纹 |
| 数量与比例 | 套装配件、家具尺寸、生鲜份量 | 增删物件、放大主体、改变摆放数量 |
| 功效与状态 | 食品新鲜度、美妆功效、电子性能 | 添加认证、夸大新鲜/性能、生成使用效果 |

| 处理档案 | 典型商品 | 最高允许处理层 |
|---|---|---|
| `PACKAGING_STRICT` | 包装食品、美妆、带型号电子产品 | 原前景 + 白底/模板背景；不调用背景生成 |
| `ELECTRONICS_STRICT` | 手环、手机、家电、配件 | 原前景 + 中性棚拍背景；锁定屏幕/接口/型号 |
| `PRODUCT_STANDARD` | 杯具、日用品、鞋包、厨具 | 原前景 + 可生成棚拍背景 |
| `ORGANIC_CONSERVATIVE` | 果蔬、鱼虾、肉类、散装农品 | 原前景 + 静态/冷链背景；不改变鲜度、颜色或数量 |
| `FASHION_LIMITED` | 平铺服装、鞋包、珠宝 | 主图前景锁定；真人/搭配只可作营销附图 |
| `RETAKE_REQUIRED` | 严重模糊、遮挡、无法分割、二手瑕疵不清 | 不美化，只给重拍指引 |

处理合同由后端存储，示例：

```json
{
  "riskProfile": "ELECTRONICS_STRICT",
  "allowedOperations": ["CROP", "BACKGROUND_COMPOSITE"],
  "forbiddenOperations": ["PRODUCT_REGENERATION", "TEXT_EDIT", "COLOR_CHANGE"],
  "recommendedPreset": "neutral-studio",
  "maxCostTier": "L3",
  "requiresMerchantSelection": true
}
```

图上 OCR 文本、二维码和商品描述只用于保护规则，永远不得透传成自由模型提示词。

## 4. 免费优先的成本路由

| 层级 | 能力 | 成本原则 | 触发条件 |
|---|---|---|---|
| L0 | `sharp` 矫正方向、WebP、画布、裁切预览、质量提示 | 0 元模型 API | 所有图片 |
| L1 | OpenCV 规则：模糊、过曝、主体占比、背景杂乱、4:5 安全裁切 | 0 元模型 API | 所有图片 |
| L2 | 主体分割 / OCR / 蒙版 | 优先本地开源；低置信度才用低价托管视觉 | 商家要求清理背景，或 L0 判定背景影响展示 |
| L3 | 仅背景生成 | 受预算和商家动作控制 | 风险档案允许、蒙版合格、商家明确选择 |
| L4 | 高阶创意场景 | 运营人工审核，最高成本 | 只用于营销附图，绝不默认发布 |

“免费”不等于所有效果都免费：背景复杂时，若不做分割，就无法在不改变商品主体的前提下做出好看的图。L0 的亮度/对比度仅可作为预览、质量诊断或背景层处理；严格档案的前景必须使用上传安全处理后确定下来的**规范源像素**直接合成，之后不得再对前景调色、锐化或重编码。首期优先使用阿里云商品分割 `SegmentCommodity`：官方说明支持单件、多件和复杂背景的四通道商品前景；这比自建 GPU 更快落地，单次成本应在接入前以当前控制台为准。([能力总览](https://help.aliyun.com/en/viapi/developer-reference/api-overview))

仅在需要背景氛围时使用 `wanx-background-generation-v2` 且指定 `model_version=v3`。它是商品背景模型，当前公开标价 0.08 元/张、支持透明 RGBA 主体和图/文背景引导；结果 URL 只有 24 小时有效，必须下载回平台 OSS。模型输入限制明确不应包含大段文字或图文混排，因此包装类默认禁止走它。([背景生成 API](https://help.aliyun.com/zh/model-studio/wanx-background-generation-api-reference))

高阶 `qwen-image-3.0` / `wan2.7-image` 不是主图默认路径：前者只可在运营审核的附图中使用，后者的 BBox 是矩形而非像素蒙版，不能证明商品事实未变。模型价格、额度、地域和 API 版本在实际开通日重新核验，禁止写死调研报价。([百炼价格](https://help.aliyun.com/zh/model-studio/model-pricing), [Wan 2.7 编辑](https://help.aliyun.com/zh/model-studio/wan-image-generation-and-editing-api-reference))

## 5. Agent 的六个受限角色

| 角色 | 输入与输出 | 权限边界 |
|---|---|---|
| 资产守卫 | 不可变原图、哈希、商户归属 | 只接受受管资产 ID，不接受任意 URL |
| 图片诊断员 | 质量分、风险轴、重拍理由 | 只输出 JSON，不产生图片 |
| 构图策划员 | 处理合同、画布/模板选择 | 不能升高成本层级，不能写自由提示词 |
| 保真渲染员 | 原前景、蒙版、静态背景、阴影 | 合成而非重绘主体 |
| 背景创作员 | 透明主体、受控背景模板 | 只产生背景；产物须再覆盖原前景 |
| 真实性审核员 | 原前景、成品、OCR 区域、来源信息 | 可拒绝/告警，不能放行或采用 |

必要的二次闸门：

- 最终合成必须确定性执行：生成结果在“蒙版膨胀后的主体保护区”全部丢弃，保护区仅以规范源前景按记录的几何变换回贴；最终受保护区域必须通过逐像素 RGB/Alpha 一致性校验，而不只是保存输入 hash。
- 多件套须保存每个选定主体的蒙版连通域；合成后校验每个连通域都在安全画布内，不能以裁掉配件/部分主体的方式通过验收。
- OCR 对比发现包装文字、条码、型号或二维码区域被改变，直接拒绝候选。
- 新出现的文字、价格、Logo、认证、人物或额外商品，直接拒绝候选。
- DINOv2 / 视觉模型只能做“主体可能异常”的告警，不能充当真实性证明。
- 透明/强反光/缠绕套装、海鲜多主体、低清图默认要求商家框选主体；框选仍低置信度则降级重拍。

## 6. 资产、任务与现有媒体的关系

现有 `ProductMedia` 只有 URL/排序，且保存商品时按 `mediaUrls` 全量删除重建。因此候选图不可直接混进现有列表，未采用图也不能被草稿自动保存公开。

第一步必须增加不可变受管资产和候选任务，而不是直接给 URL 调模型：

```text
SellerMediaAsset (规范安全源、商户归属、hash、尺寸、OCR/蒙版)
        ↓
ProductImageOptimization (合同、任务、成本预占、候选、审核结论)
        ↓ 商家采用后
ProductMedia (展示顺序；保留原实拍与 AI 优化标识)
```

`SellerMediaAsset` 至少记录 `companyId/uploaderId/objectKey/canonicalSha256/purpose/width/height`；其中 `objectKey/canonicalSha256` 指经 EXIF 剥离、转码和联系方式安全处理后的规范安全源，不是原始未处理上传。`ProductImageOptimization` 至少记录来源资产、商品/草稿可选关联、处理合同、provider/model/promptVersion、幂等键、状态、成本预占/结算、候选资产、采用人和时间。

任务状态：

```text
REQUESTED → QUEUED → RUNNING → SUCCEEDED → ADOPTED
                              ├→ FAILED | REJECTED | EXPIRED
                              └→ RECONCILING → SUCCEEDED | FAILED | EXPIRED
```

- `原图 hash + 处理合同版本 + 模板版本 + 模型版本` 是缓存键。
- 同键运行中任务只能有一个；超时先查供应商任务状态，不可直接重试。
- 额度预占、任务创建和幂等键在同一事务；失败/拒绝释放预占，成功后结算。`QUEUED` 可因尚未提交而过期；但付费供应商在 `RUNNING` 租约到期时若可能已经受理请求，必须先进入 `RECONCILING` 并查询任务/费用，绝不能直接过期、释放去重锁或再次提交。
- 采用也必须条件更新，防止多端双击把同一候选写入两次。

## 7. 卖家、买家与管理端

### 卖家中心

入口仍在商品创建/编辑页的“商品图片”卡片中，不和“AI 搜索优化”混在一起。每张已完成上传图有“优化图片”动作；创建页未保存商品也能依赖受管资产发起任务。

商家只选择“真实白底主图”“专业棚拍主图”“场景灵感图”，随后在对比弹窗中查看原图/候选图。采用前必须确认：

1. 商品数量和配件完整。
2. 包装、型号、文字、二维码没有变化。
3. 颜色、规格、重量、材质和瑕疵描述与实物一致。

草稿/未上架商品的动作只有“保留原图”“设为主图”“添加为详情图”，采用为主图将候选加入待提交的媒体排序，原图仍保留为详情实拍图。**已上架商品没有“立即设为主图”动作，只有“提交封面变更审核”。**

已上架商品采用候选时必须创建不可变 `ProductMediaRevision(PENDING_REVIEW)`；买家查询永远读取最近 `APPROVED` 的媒体版本。管理端审核通过后，才在单个事务中原子切换公开版本与封面排序；驳回、撤回或过期时，买家继续看到原已审核版本。候选、原图和采用申请均保留审计记录。

### 买家端

商品流使用采用后的封面；详情页展示低干扰“AI 优化展示图”标识，并固定保留至少一张包装/规格/细节实拍。所有图片仍需匹配现有商品卡的 4:5 安全裁切，避免 9:16 上传图在 `contentFit=cover` 中截断主体。

### 管理端

管理端需要“商品视觉治理”：查看资产谱系、任务、模板、模型、商家采用记录、额度与投诉；可以撤回候选封面并恢复原图。管理端审核商品时可要求补充实拍证据图。

## 8. 安全、合规与运行开关

- `AI_PRODUCT_IMAGE_ENABLED=false` 为默认关闭；未配置 provider、预算或地域不匹配时 fail-closed。
- 仅 `OWNER/MANAGER` 可创建、采用、恢复候选；所有接口按 `companyId + assetId` 鉴权。
- 浏览器不接触供应商 Key、裸任务响应或可复用的 OSS URL；服务端只把短期受控输入交给供应商，并把结果下载回平台。
- 生成结果须重新走 MIME、大小、解码、WebP、元数据与内容安全检查；不得使用跳过用户文件校验的内部 `uploadBuffer()` 直接落库。
- 显示层和文件元数据保留 AIGC 标识，不能删除；具体上线方式和用户协议在上线前由合规复核。([标识办法说明](https://www.cac.gov.cn/2025-03/14/c_1743654685896173.htm))

## 9. 分期与验收

1. **Phase A：免费基础层** — 受管资产、L0/L1 诊断、4:5 预览、重拍指引、原图留档；无生成模型。
2. **Phase B：保真主图** — 分割/OCR/蒙版、白底与模板合成、任务和商家采用闭环。
3. **Phase C：背景候选试点** — 白名单商家与低风险商品启用 L3；每次 1 张、预算/并发受限、人工采用。
4. **Phase D：转化实验** — 对同一商品稳定分桶测试原封面与采用封面，观察点击、加购、付款及退款/图片不符投诉。
5. **Phase E：高阶创意** — 仅在保护指标稳定后，为服饰/家居开放审核后的营销附图。

必须验证跨商户越权、任意 URL/SSRF、重复任务、超时重试、额度竞态、媒体删除时任务回写、包装文字保护、采用幂等、重新审核、原图恢复、AIGC 标识和真实供应商失败回退。
