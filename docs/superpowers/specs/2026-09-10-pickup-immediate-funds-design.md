# 自提核销无售后与基金即时释放

## 已确认需求
自提核销成功即完成履约，不再接受新售后申请。核销后立即计算平台基金，产业基金直接进入公司可支付余额，不设置售后冻结期。钱仍由平台保管，公对公付款继续独立登记。快递订单不变。

## 实施边界
- 自提核销仍以 Serializable 事务、READY/PAID CAS 和一次性凭证为准。收货时间和售后截止时间均为核销时间，不增加等待期。
- 保留现有可靠收货 outbox：核销提交后立即调度分配，失败自动重试，不能因为副作用故障丢失记账；即时表示无业务冻结期，不承诺跨事务同步完成。
- 公司产业基金在同一记账事务完成计提与释放，保留完整流水和稳定幂等键。只有 PICKUP + RECEIVED + PICKED_UP 的订单可走即时路径；已有进行中售后继续阻止释放。
- 平台利润、慈善、科技、备用金现有收货直接入账机制保持。个人奖励的层级/消费次数、队列达标、团购返还资格等独立业务条件不在本次基金规则修改范围。
- 后端售后资格查询和创建入口统一拒绝自提订单的新申请，包含直接 API 调用；App、小程序隐藏新申请入口，保留已有售后记录及处理。
- 不批量回填或重算历史个人账。现存公司冻结款（包括反馈的 3.01 元）不通过本次代码变更直接改库，单笔处理需核实来源、核销与已有售后后独立执行。

## 验证
核销时间窗口精确等于核销时刻；自提售后查询/创建拒绝，快递不受影响；产业基金核销后冻结为零、可支付准确，重复记账不重复释放；未核销和已有售后不得提前释放；两端类型检查与入口回归。
