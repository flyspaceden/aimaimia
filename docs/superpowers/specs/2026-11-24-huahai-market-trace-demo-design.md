# 华海 AI 农贸市场 · 产销溯源演示版升级设计

状态：用户 2026-11-24 已在会话中批准方向（“按方案开工，可多加页面和展示数据，UI/UX 要现代化、有科技感”）。本稿记录已确认内容与实现时的自主决定。

## 1. 目的

把“养殖端（物联网平台 + 确权小程序）→ 销售端（AI 农贸市场）”的数据链路先用演示数据完整展示出来，拿去给合作方、客户、投资方看。买家点开一个商品，能看到它来自哪家公司、哪个基地、哪口塘、哪一批，以及生长、投喂、水质、检测等过程数据。

最终目标（不在本期）：真实数据打通、C 端和 B 端都能真实下单。

## 2. 已确认

- 只用演示数据，不接后端、不读物联网真实数据。
- 只展示物联网**现在已经记录**的数据类型：公司/基地/塘、批次与来源链（放养、补苗、转塘、分塘、混塘、起捕）、饲料产品与批号及投喂量、死亡记录、水质历史与实时读数、预警、机构检测（药残/病菌/无抗）、照片、数据修订与来源。
- 用药记录、施肥记录、定期称重生长曲线目前没有，**本期不展示**。
- C 端和 B 端都做；页面全程标注“演示版”。
- 在现有 `huahai-market-site/` 上升级（无框架 TypeScript + CSS 静态站，保留严格 CSP、无外部请求），不换技术。
- 本地完成后先给用户看，发布到 `market.huahainongke.com` 前另行确认。

## 3. 方案取舍

| 方案 | 取舍 | 结论 |
|---|---|---|
| 在现有静态站上升级 | 已有部署目标、CSP 与测试；改完即可上线演示 | **采用** |
| React/Vite 重写 | 对演示无额外收益，需改 CI 与部署 | 不采用 |
| 溯源页做进物联网平台 | 面向养殖户/管理者，不面向买家 | 不采用 |

## 4. 页面（hash 路由）

| 路由 | 页面 | 主要内容 |
|---|---|---|
| `#home` | 首页 | 主视觉“每一条鱼都有数据档案”、实时平台指标、批次码查询、精选可溯源商品、“塘口到餐桌”链路、基地入口、AI 助手入口 |
| `#shop` | 买好货（C 端） | 商品网格、品类筛选、排序、溯源完整度与检测合格标识 |
| `#product/<id>` | 商品详情 | 规格/价格/加购，溯源摘要（公司›基地›塘、AI 解读、关键指标），进入完整档案 |
| `#trace/<批次码>` | 溯源档案 | 身份信息、AI 解读、来源链图、养殖时间轴、饲料投喂、水质曲线（含达标区间）、预警摘要、机构检测逐项对照、照片记录、数据确权（来源构成、修订记录、指纹）、扫码溯源 |
| `#bases`、`#base/<id>` | 产地基地 | 公司与基地列表；基地塘口分布图、每口塘实时水质、在塘批次与预计上市 |
| `#source` | 产地采购（B 端） | 货源大厅（在塘存量、预计起捕、批次链接）、采购需求、未来 8 周供货日历 |
| `#work` | 交易工作台（B 端） | 沿用并加强：订单履约节点、报价核对、交付清单 |
| `#cart`、`#checkout`、`#order/<id>` | 购物车与演示下单 | 购物车、确认订单、模拟支付成功、订单详情（每件商品可回到溯源档案） |
| 浮层 | AI 助手 | 按当前商品/批次给出预设问答（“打过药吗”“水质怎么样”“吃什么饲料”等），回答只引用演示档案中的数据 |

## 5. 演示数据

- 1 家公司（华海农科），3 个基地（阳江海陵、茂名电白、湛江东海岛），13 口塘（其中 7 口有在塘批次，B 端在塘存量与周供货量均由这些批次推出，周供货合计不超过在塘存量）。
- 6 款水产商品，各对应一个完整批次；其中一批演示“转塘”，一批演示“分塘”来源链。
- 水质为按日生成的确定性曲线（同一批次每次结果相同，保证截图稳定），带适宜区间；越线点只出现在有预警记录的日期，且数值取自预警记录。
- 检测报告为虚构机构名称与编号，并逐项注明“演示”。

## 6. 视觉方向（自主决定，可调整）

- 浅色科技风（用户 2026-11-24 改定，不用深色背景）：沿用已确认的官网绿白配色——浅绿灰底 #f5f8f6、白色卡片、主绿 #15803d、深绿文字 #183b2a；青色 #0e7490 用于数据与实时状态；保留淡网格背景、渐变主按钮与柔和阴影营造科技感。
- 系统中文字体 + 等宽数字（数据读数），不引入外部字体。
- 图表、插画、图标全部为内联 SVG（商品图为风格化矢量插画，不伪装成实拍照片）。
- 实时读数轻微跳动动画；尊重“减少动态效果”系统偏好。
- 响应式：375 / 768 / 1024 / 1440 无横向溢出；触控目标 ≥ 44px。

## 7. 边界

- 不产生任何网络请求、存储或真实交易；购物车只在当前页面内存中，刷新清空。
- 不展示“已上链”“认证”等未接入能力；“数据确权”只展示来源、修订和指纹的呈现方式。
- 不修改集团官网、物联网平台、爱买买 App/后端。
