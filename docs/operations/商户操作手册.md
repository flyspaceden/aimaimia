# 爱买买 · 商户操作手册（测试版）

> 仅用于测试阶段。包含：**如何入驻 · 如何登录 · 如何上货 · 如何配置并核销到店自提订单**。

---

## 一、如何入驻

1. 打开官网入驻页：**https://ai-maimai.com/merchants/apply**
2. 填写申请表：
   - 企业/店铺名称（二至五十个字）
   - 经营品类（下拉选择）
   - 联系人姓名
   - **联系手机号**（审核通过后，此号码就是你登录卖家后台的账号）
   - 联系邮箱（选填）
   - 上传营业执照（图片或电子文档，单个文件不超过五兆）
   - 输入图形验证码（看不清可点图片刷新）
3. 点击"提交申请"。
4. 一至两个工作日内，平台管理员审核。
5. 审核通过后，申请时填写的手机号会收到短信通知，即可前往卖家后台登录。

---

## 二、如何登录

1. 打开卖家后台：**https://test-seller.ai-maimai.com/**
2. 页面顶部有两种登录方式，任选其一：
   - **短信登录**：输入手机号 → 点"获取验证码" → 收到短信后填入六位验证码 → 点"登录"。
   - **密码登录**：输入手机号 + 图形验证码 + 密码 → 点"登录"。首次登录请先用短信方式。
3. 如果你的手机号关联了多家企业，登录后会出现"选择企业"页面，点击要进入的那家即可（此页面五分钟内有效，超时需重新登录）。

> 忘记密码、或收不到短信时，请联系平台管理员处理。

---

## 三、登录后如何上货

1. 登录后默认进入**工作台**。点左侧菜单"**商品管理**"。
2. 点右上角"**新增商品**"。
3. 按顺序填写：

   | 填写项 | 说明 |
   |---|---|
   | 商品标题 | 二到八十个字 |
   | 商品分类 | 从树形菜单中选到最末一级 |
   | 商品主图 | 最多九张，第一张是封面 |
   | 商品详情 | 支持图文混排 |
   | 退换货政策 | 如"七天无理由"等 |
   | 自定义属性（选填） | 如"产地=山东" |

4. 往下滚，**添加规格**（也就是每一种口味、重量、包装各一条）：

   | 规格字段 | 说明 |
   |---|---|
   | 规格名称 | 如"一公斤装 / 红富士 / 礼盒装" |
   | 成本价 | 你的进货成本 |
   | 售价 | **系统自动计算 = 成本 × 一点三**，不能手动改 |
   | 库存 | 初始数量 |
   | 单笔限购 | 填 0 表示不限 |
   | 重量（公斤） | 用来算快递费，必须大于零 |

5. 点最底部"**保存**"。
6. 提交后商品进入"**审核中**"，平台管理员通常一个工作日内完成审核。
7. 审核通过后，回到商品列表，把该商品那一行的"**上架开关**"打开，商品就会出现在买家端。

> 审核被驳回时，商品详情页顶部会显示驳回原因；按原因修改后再次保存，会自动重新提交审核。

## 四、如何配置到店自提

> 该功能默认关闭。只有测试环境完成数据库迁移、配置 `PICKUP_TOKEN_SECRET` 并打开 `PICKUP_FULFILLMENT_ENABLED` 后才会显示真实数据。

1. 用 OWNER 或 MANAGER 账号登录卖家后台，打开左侧“自提点管理”。
2. 点击“新增自提点”，填写点位名称、联系人、手机号、省市区、详细地址、每周营业时间和取货须知；有经纬度时可同时填写导航位置。
3. 保存后确认状态为“启用”。停用点不会再出现在新结算中，但历史订单仍显示付款时冻结的地址和营业时间。
4. 联系手机号属于履约信息，仅填写门店工作号码；不要填写与取货无关的个人号码。

## 五、如何处理自提订单

1. 在“订单管理”选择“自提订单”或履约方式“到店自提”。此类订单不会生成顺丰面单，也不需要点击快递发货。
2. 商品准备完成后，在订单列表或详情点击“备货完成”。订单会进入“待自提”，买家才能看到二维码和 8 位取货码。
3. 买家到店后，核对订单和自提人信息，再扫描买家二维码，或人工输入完整 8 位数字取货码。
4. 核销成功后订单立即进入“已取货/已收货”；该动作不可撤销，不得在买家尚未拿到全部商品时提前核销。
5. 二维码过期时让买家重新打开凭证页刷新；不要拍照保存或在聊天中长期转发取货码。
6. 如果订单显示“履约信息异常”、买家要求 READY 后取消，或核销结果不确定，请停止重复操作并联系平台管理员。普通商品由管理员走受控取消退款；团购和 VIP 礼包必须走各自专项处理流程。

## 六、权限与审计

- 自提点新增/编辑只允许 OWNER、MANAGER；核销和订单查看仍受本企业订单权限限制。
- 点位启停、备货、核销和平台退款均记录操作者与时间；管理员停用点位还记录变更前后状态和原因。
- 卖家后台不会显示可导出的长期有效凭证；核销输入有频率限制，连续失败时先核对订单，不要反复尝试。
