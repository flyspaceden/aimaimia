## 2. 执行批次与成本上限

### Batch 0：免费分析 40/40

- 只执行本地质量诊断、方向推荐和事实风险分类，不调用图像生成模型，不冻结图片额度。
- 先确认每张图适合“保留真实场景 / 电商棚拍 / 商品精修 / 营销场景”中的哪一类；不得默认全部改白底。
- 无法确定文字、条码、数量、颜色或结构事实的样本标记为高风险，不进入自动采用。

### Batch 1：标准档 canary 8 张

- 选择 S01、S06、S11、S16、S21、S26、S31、S36，覆盖八种主体/困难条件。
- 使用 8 × 15 = 120 额度；每张只生成 1 个候选。
- 全部人工逐项评分并完成 Provider 成本对账后，才能进入 Batch 2。

### Batch 2：高质量档 canary 4 张

- 从 Batch 1 中选事实门禁通过但标准档提升不足的 4 张，不预先写死为固定图片。
- 使用 4 × 35 = 140 额度；每张只生成 1 个候选。
- Batch 1 + 2 商家报价总上限 260 额度，展示服务面值 ¥26；这不是 Provider 成本。

### Batch 3：扩展到剩余 28 张

- 只有前 12 张无事实硬错误、无重复扣费、对账闭合且主要类别确有可售提升时才执行。
- 执行前根据真实 Provider 单价和实际使用量另行批准预算；本表不自动授权后续费用。

## 3. 单张评分表

每张原图和候选图由至少两名评审独立打分，分歧超过 1 分时共同复核。

| 维度 | 1 分 | 3 分 | 5 分 | 是否硬门禁 |
|---|---|---|---|---|
| 商品事实一致 | 明显改变事实 | 有不确定区域 | 数量、颜色、结构、文字均一致 | 是，必须 5 |
| 主体清晰与材质 | 更糊或假塑料感 | 有改善但局部失真 | 清晰自然且材质可信 | 否 |
| 构图与背景 | 更杂乱/抢主体 | 基本可用 | 主体突出、场景合理 | 否 |
| 光线与颜色 | 失真、过饱和 | 大致自然 | 自然、准确、有购买吸引力 | 颜色敏感图必须 5 |
| 商业可售性 | 不愿展示 | 可作为详情图 | 明显优于原图并愿作主图 | 否 |
| AI 痕迹 | 明显重绘/畸变 | 少量可见 | 无明显伪影 | 否 |

通过标准：

- 不触发任何硬拒绝条件；事实一致必须为 5。
- 六个维度平均分不低于 4.0，且商业可售性不低于 4。
- 至少 70% 的样本相对原图商业可售性提升 1 分以上。
- “保留真实场景”样本中，不合理改成白底/浅色背景的比例必须为 0。
- 明确文字、二维码、条码、数量或关键结构错误的候选自动拒绝，不允许靠综合平均分通过。

## 4. 逐笔结果与费用字段

每次真实执行必须记录以下最小证据，不记录 Key、OCR 原文、条码内容或完整 Provider 响应：

| 字段 | 说明 |
|---|---|
| candidate SHA / deployed SHA | 证明执行的代码版本 |
| sampleId / authorizationRef | 样本编号与授权凭据引用 |
| source canonical hash | 证明原图未被替换；仅保存摘要 |
| tenant/client/adapter namespace | 证明调用范围 |
| rateCard version / quoteId / quoteHash | 证明商家看到并确认的价格快照 |
| invocationId / providerTaskId / requestId | 逐笔对账，不公开给商家 |
| model / direction / risk profile | 服务端实际路由 |
| credits reserved/settled/released | 图片额度流水 |
| provider actual cost cents | 来自 Provider 记录或账单，不用额度倒推 |
| verification summary | 仅结论、长度、数量和风险，不含敏感原文 |
| reviewer scores / rejection reason | 效果和事实验收 |
| adopted / rolled back | 商家选择和平台事后治理 |

## 5. 停止条件

出现以下任一情况立即停止后续付费样本、关闭对应执行开关并进入审查：

- 商品数量、颜色、关键结构、文字、二维码、条码或真实瑕疵被改变。
- 同一 Quote/Invocation 发生重复 Provider 提交或重复扣额度。
- Provider 已受理但本地记录成普通失败，导致可再次发起收费请求。
- Provider 实际成本无法与 invocation/quote/ledger 一一对上。
- 输出 URL 不属于精确允许域、下载摘要不匹配或候选文件无法验证。
- 标准档连续 4 张商业可售性无提升，或主要效果只是手机本地滤镜级调整。
