# 华海官网大健康知识库

## 范围与入口

2026-10-11 用户将正在发布的官网农事入口调整为顶部“大健康知识库”栏目，包含“农事上下五千年”“药食同源（知识）”“今日健康食谱”。`health.html` 提供总览，三个主题分别位于 `agriculture.html`、`food-medicine.html`、`healthy-recipes.html`。首页原农事条和弹窗移至农事专页，原公司正文与数字讲解保留。

已有主导航的公开页与数字讲解页加入统一展开菜单，支持点击、Tab、Escape、点击外部关闭和移动端滚动。电脑窗口优先使用原单行导航，按实际内容宽度折叠过长的外语栏目。主题页有中文正文标签与 `lang="zh-CN" dir="ltr" data-translation-ignore`；导航、页脚、页面标题及中文说明支持原九种译文。跨页链接保留语言参数，禁用本地存储也可使用。

配色沿用官网深绿 `#183f32`、主绿 `#126b46`、正文灰绿 `#607463` 与浅绿 `#f0f5ec`；农事阅读采用宋体节气标题，目录采用搜索、列表与展开详情，三餐采用连续阅读。

仅集团官网公开内容，不改变买家 App、小程序、IoT 大屏、后台、认证、设备配置或数据库。

## 农事上下五千年

保留大屏同版北京时间公历/农历、当前与下一节气、四季种植和水产常识、按日期轮换的 12 篇原创农事短文及参考资料。不展示宜忌，不把原创短文声称为历史文献。专页每分钟及返回页面时检查北京日期；跨午夜更新日期、农事与故事。

`tools/huahai-farming-calendar/screenCalendar.ts` 和 `agriculturalCalendarContent.ts` 与已有 IoT 农事候选保持字节一致；网页入口现在为专页阅读器。旧首页弹窗交互不再适用，本文覆盖 `huahai-farming-calendar.md` 的首页位置与弹窗说明。

## 药食同源（知识）

提供的《国家卫健委药食同源目录106种(1).docx》《国家药食同源目录106种药性简表(1).docx》是整理底稿；公开 JSON 记录两份资料的 SHA-256。目录名称与批次依据官方公告校正为 87 + 6 + 9 + 4 共 106 条，页面注明 2002、2019、2023、2024 公告范围，未声称覆盖未来新增目录。

- [2002 年通知与附件一](https://www.nhc.gov.cn/wjw/gfxwj/200203/2abc2d4088e94f129e73f74d48caa1a3.shtml)
- [2019 年第 8 号公告](https://www.nhc.gov.cn/wjw/c100175/202001/60977058ce3b4449b1b1d46cff283e73.shtml)：当归、山柰、西红花、草果、姜黄、荜茇，仅作为香辛料和调味品。
- [2023 年第 9 号公告](https://www.nhc.gov.cn/wjw/c100175/202311/59e03b384f9a4d0b9623e19b813f6cc4.shtml)及[使用条件解读](https://www.nhc.gov.cn/wjw/c100379/202311/cff8436e06ed477fa6cbbf617d1c323c.shtml)：党参、黄芪属于本批次；肉苁蓉限定荒漠品种；保留特殊人群、党参/西洋参不宜与藜芦同用和天麻过敏体质说明。
- [2024 年第 4 号公告](https://www.nhc.gov.cn/wjw/c100175/202408/15135932f4a34553b1bd88b203282ecb.shtml)及[使用条件解读](https://www.nhc.gov.cn/sps/c100087/202408/aa9a6f7bce8e4b4cbcc4b38591676ed6.shtml)：地黄、麦冬、天冬、化橘红。

原资料的山银花、芦荟不纳入这套 106 条目录。山柰、西红花没有提供传统药性，明确标为未收录。性味与归经来自提供的简表，尚未逐条独立以药典复核；不用这些字段宣称食品能预防或治疗疾病，不展示处方剂量。食品使用条件与传统药性分别展示。

目录支持名称、年份、传统性味组合筛选，陈皮/橘皮、藏红花/西红花、山奈/山柰等名称检索，16 条一页、清空筛选、空结果提示与展开资料。无 JavaScript 时仍可阅读全部静态条目。

## 今日健康食谱

七套原创一般健康成年人家常三餐搭配，按北京日期确定默认方案；用户可循环换一套。每餐含食材、做法、已列食材过敏原，附水果/奶类加餐与食材清单。借鉴[中国营养学会膳食指南](https://dg.cnsoc.org/index.html)的一般搭配原则，不复制其图形或完整文字。份量由读者结合自身需求调整，不声称已满足个人热量或营养目标，不把药食目录自动转成治疗食谱。

数据加载失败显示刷新重试与下方搭配说明，隐藏切换按钮；重新加载可恢复。北京跨日会重置手动轮换，更新当天默认方案。
