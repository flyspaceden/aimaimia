# 华海农科官网多语言

范围：`huahai-corporate-site/` 的首页、关于我们、业务版图、技术引擎、产业生态、联系我们、隐私政策和用户协议，共 8 页。此功能不改变爱买买 App、小程序、卖家/管理后台或 IoT 平台语言，也不改变 IoT 大屏访问权限。

## 支持语言与交互

支持简体中文 `zh-CN`、英语 `en`、阿拉伯语 `ar`、法语 `fr`、德语 `de`、日语 `ja`、意大利语 `it`、葡萄牙语 `pt`、西班牙语 `es`、繁体中文 `zh-TW`。默认简体中文；明确的 URL `?lang=` 优先于本地保存的选择。无有效选择时显示中文，不按浏览器地区自动替用户切换。

各页顶部提供使用语言自身名称的原生选择器，支持键盘操作。成功切换后同步标题、SEO 描述、图片替代文字、导航的可访问名称和正文，并更新 HTML `lang` / `dir`。跨页链接带上语言参数，保留已有参数及片段；本地存储可用时记住下次访问的选择。无法使用本地存储时 URL 仍可保持跨页语言。

切换只操作文字节点和展示属性，不重建页面、不替换 SVG/链接/联系方式。译文加载失败或不完整时保留当前语言并显示重试提示；快速切换以最后一次选择为准。关闭 JavaScript 时仍可阅读原有中文静态页面。

阿拉伯语采用 RTL 排版；电话号码、邮箱、备案号和数字统计隔离为 LTR。日语及繁体使用对应系统字体；第三方字体不可用时使用本地字体回退。宽度不足时导航收进菜单，语言入口保留在顶部。

## 内容与维护

9 个译文目录文件位于 `huahai-corporate-site/assets/locales/*.json`，以中文原文的完整文字节点为键。所有译文预先生成并随站点部署，浏览时只读取本站 JSON，不调用任何外部翻译服务、不需要 API 密钥。英文已修正农业核心术语；其他语言介绍页以修正后的英文为基础统一术语，繁体根据中文转换。初稿使用机器翻译，尚未经过各语言专业母语译审，不能将本次代码审查当作专业译审。

新增或修改中文文案时必须同步全部目录，运行覆盖测试；缺少对应文案时客户端拒绝半完成切换。修改译文或共享样式时同步更新 6 个介绍页和 `scripts/sync-huahai-legal.mjs` 的脚本版本参数，以刷新相关脚本、CSS 和 JSON 缓存。

隐私政策和用户协议的权威原文继续为 `src/content/legal/` 的中文源文件。本次不修改该原文或其 Word 审核稿。`scripts/sync-huahai-legal.mjs` 仅在原样生成的华海法律页后附加多语言脚本；非简体中文显示参考译文提示和“中文原文”按钮，可完整恢复中文。其他语言法律译文仅供参考，并非另行批准的法律版本。

## 验证与发布

运行 `node --test scripts/__tests__/huahai-i18n.test.mjs` 检查 8 页全部文案与元数据覆盖，以及联系方式保留。

先运行 `node website/scripts/build-legal-static.mjs`，再运行 `node --test scripts/__tests__/legal-compliance.test.mjs`，检查权威中文正文仍与其他法律页面一致。原测试先读取静态产物，干净目录需先生成。

在 `tests/` 安装其已有依赖后，运行 `npm run test:huahai`：浏览器验证 8 页 × 10 语言 × 320/390/1100/1440 px、菜单、跨页和刷新记忆、中文法律原文恢复、链接/片段、缺失或不完整译文、快速切换、禁用存储和非法语言参数。安装了 Chrome 的本地环境可设置 `HUAHAI_TEST_CHANNEL=chrome`；可通过 `HUAHAI_PLAYWRIGHT_MODULE` 指定已有 Playwright 库。测试使用系统字体回退，不替代真实手机及母语译审。

发布继续遵循已有华海独立目标 `deploy_target=huahai`。本次不修改服务器、认证、数据库或部署流程；生产发布须单独取得授权。回滚可回退本次官网提交并按华海目标部署旧版本，不涉及数据回退。
