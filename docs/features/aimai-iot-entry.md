# 大屏爱买买入口与公开介绍页

## 确认范围（2026-10-08）

- 平台、公司、基地大屏顶部保持原有单排，在公司网站入口（存在时）和时钟之间增加“爱买买 ↗”。所有获准进入大屏的角色均可见，不依赖公司/基地配置；大屏鉴权和数据范围不变。
- 新标签打开 `https://ai-maimai.com/explore?from=iot-screen`。此链接不携带用户、基地、设备或推荐人信息。
- 官网 `/explore` 为公开页面，无需登录；首屏为介绍 + 微信小程序/App 两个入口，下方介绍商品选购、配送/自提、订单管理。
- 采用用户确认的白底、农业绿设计，二维码可通过按钮放大；手机单列。下载功能覆盖安卓与 iPhone 的不同可用入口，不修改 App、小程序原生页面。

## 当前实现

- `website/src/pages/Explore.tsx`、`website/src/styles/explore.css`：独立轻量页面，不显示通用官网导航，不执行邀请绑定、指纹收集或剪贴板写入。
- App 二维码固定指向 `https://app.ai-maimai.com/download`，不编码 APK 或某一个厂商商店地址；手机点击也到该页，复用原下载页的系统、厂商和兜底判断。在微信内先展示“在浏览器中打开”指引。
- iPhone 不显示“下载安卓版”的同机操作；保留微信小程序说明。当前下载代码没有可用 iOS 安装入口，不虚构 App Store 链接。
- 小程序图片默认使用用户提供的 `website/public/images/mini-program-home-20261008.png`，原样保存为 430×430 PNG，未裁切、重绘或压缩。SHA256：`4db26538116a9d1c708c6aab209c1606d545b128a3d48bb8699209a69418d7bf`。可用 `VITE_MINI_PROGRAM_QR_IMAGE_URL` 覆盖为仓库图片路径或 HTTPS URL；显式空字符串停用。可选 `VITE_MINI_PROGRAM_URL_LINK` 仅用于已经验证的正式微信链接；未提供时以扫码/保存原图为入口，不伪造可直接打开的链接。
- 小程序路径已核对 `miniapp/src/app.config.ts`：`pages/home/index`。生成首页码时不添加推荐人、团长、团购参数；生成图片仍需微信真机扫码确认正式版本。
- 图片缺失、加载中、加载失败分别展示明确状态。未就绪时不能放大，不拿普通网页二维码冒充小程序码。
- `/explore` 和 `/explore/` 使用相同标题信息，入口已登记 sitemap。弹层支持关闭与 Escape，短屏可滚动。

## 双仓库边界

官网从最新 `origin/main`（`87e1bf1a`）建立 `codex/aimai-iot-entry-20261008` 独立 worktree。

IoT 是无 Git remote 的独立本地仓库，最新在用的新版大屏不在其早期 `main` 上。本次从已提交的新版前端基线 `6e267bab` 创建 `codex/aimai-screen-entry-20261008` 独立 worktree，仅修改共享大屏入口/布局、相关测试与文档，不回退到旧大屏。

两个仓库不共享认证、数据库或运行时依赖。IoT 中的链接是普通 HTTPS 外链。生产发布必须先让官网介绍页及正式码可访问，再发布大屏入口；不得只发布按钮而留下失效页面。
