# 华海官网今日农事

用户要求将大屏的农历、节气农事与故事也放入huahainongke.com，并确定合适位置。本地候选位于首页公司Hero介绍与“核心实力”之间，使用“今日农事”条和完整阅读弹窗。原公司介绍、数字讲解、导航和业务信息保留。

## 内容与日期

北京时间公历/农历、当前与下一节气、4季种植/水产常识、按日期轮换的12篇原创短文及其参考链接，覆盖24节气，不展示宜/忌。没有虚构真实人物、当日天气/当地作业声称，也没有药物用量或自动控制方案。

与IoT候选`huahai-iot-platform-agricultural-calendar-20261010`中的`screenCalendar.ts`和`agriculturalCalendarContent.ts`保持字节一致。固定lunar-typescript 1.8.6（MIT）、esbuild 0.25.12，依赖仅在独立开发工具目录，未变更主应用依赖。

重建：`cd tools/huahai-farming-calendar && npm ci && npm run build && npm test`。生成官网assets中的JS与源SHA清单；源码/工具/node_modules不进入公开目录。内容变动时同步两处同版本源码，比较SHA后重建，避免网站与大屏资料漂移。

## 语言与交互

入口控件和无JS说明补充原九种译文。农事正文为中文原文，以lang="zh-CN"和data-translation-ignore标识；弹窗明确说明。首页脚本查询版本20261010-farming1使新增语言键避开旧缓存，其他页不变。

原生dialog支持关闭、Escape、遮罩、独立滚动及焦点恢复。背景滚动锁定；北京午夜更新首页条，已打开正文保留点击日期。禁用JS时提供公开气象资料链接。
